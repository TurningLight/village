# 本地实景模型上传与测试

## 启动页面

在项目目录执行 `npm run dev -- --host 127.0.0.1 --port 5173 --strictPort`，打开 http://127.0.0.1:5173/ 。如果开发服务已经运行，直接打开页面即可。

## 上传和替换地图

1. 在顶部场景来源中点击「地图设置」，选择「本地上传」。
2. 点击「选择模型文件 / ZIP」，选择一个 `.glb`，或包含一个 `.gltf` / `.glb` 入口及配套资源的 `.zip`。也可点击「选择文件夹」选择完整的 glTF 文件夹。
3. 等待读取、模型与纹理校验、浏览器保存完成。成功后显示「已保存为默认地图」，当前场景自动切换；关闭上传面板可查看全景。
4. 刷新页面、关闭后重新打开同一网址，都会恢复刚才的模型。
5. 需要新地图时，再次上传即可。解析或保存失败会显示原因，原地图保持不变。

支持 glTF 2.0，包括常见 Draco / Meshopt 网格压缩、KTX2 纹理。相关解码器随项目本地提供。GLB 推荐将纹理和缓冲全部内嵌；glTF 的 `.bin` 与图片必须一起提供，保留相对目录。模型引用网络资源时会提示将资源一起打包。ZIP 只能包含一个模型入口。文件总大小和 ZIP 解压后的大小上限均为 512 MB；实际可加载规模取决于浏览器可用存储、内存和显卡。

本次未接入 OBJ、FBX、OSGB、LAS/LAZ、3D Tiles、GeoTIFF 等格式；此类数据请先导出为 GLB / glTF 2.0。三维模型会自动居中、适配视角，页面没有从上传文件自动建立测绘地理坐标或建筑语义分割。

## 选择 Sketchfab 在线嵌入

1. 在「地图设置」选择「Sketchfab 在线」。
2. 使用内置八卦村时，直接点击「使用黎槎八卦村」。使用其他公开模型时，填写 Sketchfab 模型页面链接、嵌入链接或 32 位模型 ID，以及可选的地图名称，点击「应用在线模型」。
3. 等待模型连接校验完成。应用收到 Viewer API 的 `viewerready` 后才保存默认来源；链接无效、连接失败或超时会保留原地图。校验最长等待 90 秒。
4. 成功后自动切换场景，刷新或重新打开同网址仍使用该在线模型。在线资源继续由 Sketchfab 提供，需要联网。
5. 想切回本地模型时，选择「本地上传」，点击「使用已保存的本地模型」，无需重新上传。在线和本地切换不改变原模型标识，原模型的事件随之恢复。

可接受的链接示例：`https://sketchfab.com/3d-models/2b79987cd49c4727b1bd12aa7ab62927`、`https://sketchfab.com/models/2b79987cd49c4727b1bd12aa7ab62927/embed`。不接受任意网站链接或整段 iframe HTML。

地图设置沿用当前演示应用的管理员界面，保存范围仍是当前浏览器；本次没有新增账号登录或服务器端权限系统。

## 无需准备真实数据的测试

项目提供自行生成的简单村庄网格，**仅供功能测试，不是八卦村实景模型**：

- `tests/fixtures/models/示例村庄.glb`：单文件模型。
- `tests/fixtures/models/示例村庄-gltf.zip`：包含嵌套缓冲路径、中文纹理路径的完整 glTF 包。
- `tests/fixtures/models/gltf-folder/`：同一 glTF 模型的完整文件夹。
- `tests/fixtures/models/损坏模型.glb`、`缺少资源.zip`、`缺少纹理.zip`：用于验证失败提示和原地图保留。

建议按以下顺序验证：

1. 上传 `示例村庄.glb`，确认出现地面和八栋方形建筑。
2. 关闭上传面板，拖动旋转、滚轮缩放，测试「重置视角」「俯视视角」「切换夜间」和「实景图层」。
3. 点击模型地面或建筑，填写事件标题并「加入待办」，确认出现标记；刷新后地图、事件和标记均应恢复。
4. 打开一个新的同网址页面，确认直接显示保存的模型。
5. 上传损坏模型或缺少资源 / 纹理的 ZIP，应提示失败，当前地图继续可用；刷新后仍是之前成功保存的地图。
6. 上传完整 glTF ZIP，确认替换成功，原地图的事件不会错误显示在新地图上。再次打开同网址应显示新地图。
7. 选择在线八卦村，确认显示在线实景且刷新后仍恢复；再切回「已保存的本地模型」，确认本地地图和它的事件恢复。
8. 在在线链接栏填写非 Sketchfab 链接并应用，应提示格式错误，当前来源保持不变。

## 保存范围

本地模型文件与纹理、在线模型设置及默认来源保存在当前浏览器、当前网站来源的 IndexedDB（`village-models`），事件仍保存在 localStorage（`village-issues`）。本地文件没有上传到服务器，也没有跨设备共享；在线模型会连接 Sketchfab。

请保持同一浏览器配置和同一网址，包括协议、主机与端口。`localhost:5173` 与 `127.0.0.1:5173` 是不同的存储范围。清除网站数据、使用隐私窗口或浏览器回收存储，可能移除模型；模型原文件应自行留存。应用在成功保存后会尝试申请持久存储，浏览器是否批准由其策略决定。

每次成功上传生成新的本地地图标识；刷新恢复或在两种来源间切换时沿用原标识，事件按标识区分。替换后旧地图事件保留在本地数据中，但不出现在新地图的统计、标记和待办列表里。当前保留最新的一份本地模型文件和最近使用的在线模型设置，不提供历史本地模型切换。青禾村 Demo 提供程序化建筑与三种预设微更新。内置八卦村仅保留原有演示业务建筑统计；其他模型不自动生成建筑记录，实景模式不支持独立设施的预设改造。

## 开发验证

- `npm test`：事件流程、地图隔离、文件包处理、来源切换恢复、旧存储兼容，以及在线校验成功 / 失败 / 超时与资源清理。
- `npm run build`：TypeScript 检查与生产构建。
- `npm run lint`：静态检查。

实现参考：[Three.js GLTFLoader](https://threejs.org/docs/pages/GLTFLoader.html)、[MDN 持久存储](https://developer.mozilla.org/en-US/docs/Web/API/StorageManager/persist)、[Sketchfab Viewer 初始化](https://sketchfab.com/developers/viewer/initialization)。
