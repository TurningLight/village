## 当前接入方式

默认示例或管理员选择在线八卦村时，使用 Sketchfab 官方 Viewer API 1.12.1 在线加载作者发布的航拍摄影测量模型与纹理。SDK 随前端提供，模型仍由 Sketchfab 托管，需要联网；未抓取或绕过需要登录的原始模型下载接口。

工具栏提供「地图设置」：管理员可选择 Sketchfab 在线嵌入或本地上传。在线方式内置「使用黎槎八卦村」，也可填写其他公开模型的链接 / ID；本地方式支持 GLB、完整 glTF ZIP 或文件夹。选择保存在浏览器 IndexedDB，下次打开自动恢复。切换来源保留最新本地模型，可随时切回。操作与测试见 [本地实景模型上传与测试](./本地实景模型上传与测试.md)。

页面保留作者、平台署名和非商业使用许可链接。模型是作者简化后的实景网格，不保证测绘精度、独立建筑分割或最新村庄现状。实景图层开关控制整个网格（包括建筑、植被、地面）。夜间模式是基于航拍纹理的视觉模拟，不能去除照片中烘焙的日照阴影。

原业务问题记录保留，原业务坐标仅在显示层按比例映射至模型并通过射线贴附网格，不是实际问题的测绘坐标。页面显式标注为模拟演示；“业务建筑”数值仍是原有演示记录数，而非真实村庄建筑总数。

重置、俯视使用官方相机 API；问题与微更新标记通过官方世界坐标投影 API 跟随相机，点击仍使用原有选中状态。原先程序生成的场景组件保留在源代码中，但不再作为当前页面的真实村庄模型。

## 村内选点与待办事件

点击模型中的建筑或地面，可录入标题、事件类型、关注程度与补充说明。使用 Viewer API 的精确拾取事件，保存命中位置到问题记录的可选字段 `sceneAnchor: { modelId, position: [x, y, z] }`。新事件使用该模型世界坐标投影，不依赖当前相机缩放；点击未命中网格的空白处不会创建事件。

当前统一的“治理事件”面板展示全部记录，支持类别与状态筛选。待处理、处理中、已办结事件以不同颜色与文字区分。点击事件标记或列表行同步镜头、地图与详情；可受理、记录处理说明、确认办结及重新受理。全量视图保留绿色办结标记；筛选待处理或处理中时会自动移除办结项。原始记录与历史保留。

继续使用 `village-issues` localStorage 存储键，兼容原有记录，刷新可恢复新事件、模型选点与办结状态。数据仅保存在当前浏览器，尚未接入服务器或多用户同步。存储失败时保留原状态并显示错误；重复办结不会增加重复历史。填写期间再次点击模型不会覆盖未保存的输入。

## 离线部署

八卦村原始模型仍需从作者官方页面取得经授权的源文件。取得完整 GLB/glTF 与纹理后，可在「地图设置 → 本地上传」使用 Three.js 查看，无需再访问 Sketchfab。前端应用本身仍需由本地或部署的 Web 服务提供；没有添加离线应用缓存。

## 当前桌面工作区

新增默认的程序化“青禾村Demo”，与实景模式分开，保留既有 Sketchfab / 本地模型来源。预设微更新在青禾村独立设施对象中实现，实景模式不再把方案文字展示当作模型改造。实景二维地图现从当前模型生成带纹理的俯视底图，事件使用同一投影参数定位，不再仅显示相对位置点。本地模型为正交投影，Sketchfab 为小视角近似俯视影像，不代表真实地理配准。详见《通用实景投影》。

## 验证

当前阶段构建、测试和浏览器记录见 [桌面阶段验收](./桌面阶段验收.md)。本地 GLB 已在统一工作区实测上传、展示、选点和刷新恢复。Sketchfab 在线初始化、失败与超时仍有自动回归测试；在线加载依赖网络及平台可用性。
