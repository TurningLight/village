# 手机端之前的阶段验收

日期：2026-10-21。范围对应确认计划第1—4项；本轮没有开发 `/mobile`、治理分析图表或后续独立导航页面。

## 完成内容

1. 青禾村程序化场景：20栋建筑，双坡屋顶、四坡屋顶、平屋顶三种造型，部分院墙、门窗及公共建筑；共享道路、农田、水系、实例化树木、广场、路灯和垃圾设施。支持建筑选择、高亮、详情、相机跟随、重置、俯视和昼夜照明。
2. 完整空间类型与共享布局：Village、Building、Road、Field、WaterBody、Facility、Issue、RenovationPlan。3D与GeoJSON复用对象ID和几何，坐标转换按演示纬度修正经度距离。保留本地仓储边界与同源数据通知。
3. MapLibre本地图层：建筑、道路、农田、水域、设施和事件；支持拖动、缩放、图层控制、点选、Popup、图例、方向和比例尺。提供小地图、独立地图和分屏，视图变化由ResizeObserver调整尺寸；WebGL失败时提供可缩放及可点选的简化平面图。
4. 治理闭环：选点新增、类别/状态筛选、受理、处理中、处理说明、办结、重新受理和时间线；统计、标记、列表共用数据与筛选。已办结记录保留，状态筛选可以只看待办。
5. 三种真实场景改造：故障路灯恢复发光；广场增加长椅、树木和铺装；垃圾点清除散落物，新增四类设施、遮棚、支撑柱与树木。预览不自动修改事件办理状态。
6. 保留Sketchfab、本地模型上传、IndexedDB恢复与按模型隔离事件。升级至React19、Fiber9与兼容Drei，并更新类型声明。

## 保留边界

- 青禾村业务和布局为演示；实景二维底图从原模型生成，事件与底图使用同一投影参数，但尚未地理配准。上传模型不自动分割建筑，不统计真实建筑数量。
- 预设改造依赖程序化设施对象，仅在青禾村Demo中使用。Sketchfab需要联网，在线实景夜间是视觉模拟。
- 数据仅保存在当前浏览器、当前网站来源。已有本地模型不会上传到服务器。同源同步使用storage事件，不支持不同设备同步。
- 没有新增账号、后端、PostGIS、通用3D编辑器、移动端或离线应用缓存。
- WebGL失败提示和简化地图已实现；本轮实际浏览器功能验收在支持WebGL的环境下完成，未通过修改浏览器配置强制关闭GPU。
