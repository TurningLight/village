# 手机端开发与测试

当前为独立的村民 H5，沿用乡居共治品牌。已有首页、随手报、进度和我的；桌面管理端仍独立运行。手机自动跟随电脑最后选择的真实村庄，以电脑共享的三维模型投影作为二维地图，不提供青禾村 Demo 或手动选村。地图保持输入模型的纹理与分布，但没有核实地理配准时不表示真实 GPS。完整联动规则与选点验收见 [手机实景底图与录入](手机实景底图与录入.md)。

## 启动与地址

需要 Node.js 22.16+（使用内置 `process.loadEnvFile`、Fetch 和 AbortSignal）。

```sh
npm ci
npm run dev
```

| 服务 | 开发地址 | 作用 |
| --- | --- | --- |
| 桌面管理端 | http://localhost:5173/ | 3D/2D、事件办理、微更新 |
| 手机村民端 | http://localhost:5174/mobile | 村民日常上报和进度 |
| 手机 HTTPS | https://电脑IP:5175/mobile | 单独运行 HTTPS 入口，真机录音 |
| 共用本地 API | http://127.0.0.1:5190/api/health | 实景底图、事件持久化与模型代理 |

`npm run dev` 同时启动三个进程，Ctrl+C 一起停止。已有端口占用时启动失败，不自动漂移到另一端口。也可以在三个终端分别执行 `npm run dev:api`、`npm run dev:web`、`npm run dev:mobile`。两端有独立HTML、入口、样式、构建产物及Vite依赖缓存，手机包不加载Three.js或MapLibre。

手机与电脑接入同一局域网，用电脑局域网IP替换localhost，例如 `http://电脑IP:5174/mobile`。HTTP局域网地址可测试文字、选点、照片与进度，真机录音需通过有效证书的HTTPS地址访问；浏览器仅对localhost等可信环境开放录音能力。不要绕过证书警告。

```sh
npm test
npm run lint
npm run build
npm run start
```

生产构建分别保存在 `dist/web` 和 `dist/mobile`；`npm run start` 同时启动API、桌面5181和手机5184。`npm run preview:web` / `npm run preview:mobile` 仅预览各自构建，须另启动API。可通过 `.env.local` 配置API_PORT、WEB_PORT、MOBILE_PORT和HOST；开发页面端口固定5173/5174。

## 建议验收顺序

1. 打开桌面5173并选择真实村庄，等待二维底图生成且显示手机同步成功。打开手机5174（录音用HTTPS5175），确认村名自动一致，首页显示该村的事件计数；首次没有实景时应显示等待。
2. 点击「随手报」，不填写提交应显示校验提示；填写标题、类别、具体说明、位置文字。
3. 打开实景地图选点，确认建筑纹理和电脑底图一致。尝试拖动、双指缩放、完整范围复位和轻点，再「使用这个位置」。拖动、缩放和图像外留白不能意外落点；地图不自动产生 GPS 坐标。
4. 从相册选择照片或真机拍照，确认缩略图和移除按钮；最多4张，单张原图不超过12MB。照片会压缩为最大1280边长JPEG。
5. 关闭上报后重新进入，确认草稿恢复；刷新后仍恢复。提交成功后显示回执，草稿清空，详情能预览照片。
6. 桌面保持同一真实村庄，在「治理事件」找到同名上报，核对二维点位，填写处理说明并受理或办结；手机随后自动显示状态和时间线，无需刷新。
7. 手机进度页测试搜索、状态筛选、只看我的、地图和列表；我的页测试称呼、上报记录、草稿、帮助及隐私说明。
8. 在桌面切换另一个真实模型，确认手机下一轮同步切到新村，不混用旧图和事件。新村没有投影时显示等待；回到旧村可恢复该村草稿。重新生成投影后，未提交表单要求重新选点，旧版无可靠三维锚点的记录只保留列表入口。中断API后，手机显示服务连接提示；提交不能虚假成功，草稿保留。重启API后恢复同步。重复点击或失败重试不覆盖已受理事件。
9. 配置语音密钥后，在HTTPS真机测试长按→首次授权麦克风→说话→松开。验证上滑取消、少于0.6秒提示、60秒自动结束、切后台停止、处理中取消。
10. 语音成功后核对字段、编辑后提交；整理失败时展开「语音原文」修改并重试，无需再次录音。标题、类别、地点已有手填内容时予以保留，语音说明追加，地图位置仍需本人确认。

## 语音密钥与现有真机配置

用户已完成配置并确认 vivo 手机 HTTPS 和录音测试可用。本轮不需要重新生成同一 IP 的证书或重复安装手机 CA。完整的申请、填写和局域网HTTPS真机步骤见 [语音配置与手机HTTPS测试](语音配置与手机HTTPS测试.md)。项目新增 `npm run dev:mobile:https`，证书准备后在独立5175端口启动，不影响原有两个页面。

复制项目根目录的 `.env.example` 为 `.env.local`，只在该文件填写北京地域百炼API Key：

```dotenv
DASHSCOPE_API_KEY=你的北京地域密钥
DASHSCOPE_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
DASHSCOPE_ASR_MODEL=qwen3-asr-flash
DASHSCOPE_TEXT_MODEL=qwen-plus
API_PORT=5190
```

重启API进程，重新进入手机上报页。不要加 `VITE_` 前缀，也不要将密钥放入客户端或发到对话里。未配置时页面显示「语音服务暂未开通」，不会请求麦克风或伪造识别结果。

录音由MediaRecorder采集，经Web Audio转为单声道16kHz PCM WAV；松开后请求 `/api/voice/transcribe`，再把原文请求 `/api/voice/format`，两次使用不同模型。模型结果需通过服务端字段白名单，再填入表单供本人核对。音频仅驻留请求内存，不写入本地文件；转写文本会成为表单内容及本机草稿，提交后事件文本和照片存到本地演示服务。照片不会传给语音模型。服务端处理超时、无语音、上游鉴权、限流和无效JSON，响应不会包含密钥或上游原始错误。

官方接口参考：[Qwen语音识别](https://help.aliyun.com/zh/model-studio/qwen-asr-api-reference)、[OpenAI兼容文本接口](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions)。用户已确认真机测试可用；本轮实景功能验收不额外执行付费语音调用。

## 数据与部署边界

事件和照片的共用文件为 `.local-data/issues.json`，原子写入、队列串行提交；本地文件不会随前端构建上传。两端浏览器保留 `village-issues` 副本。新事件先由服务器确认持久化，成功后才显示回执。首次启动会将既有浏览器事件合并入共用服务，较旧副本不会覆盖较新的办理记录；同一上报ID重试只返回原记录。

共享实景目录与 PNG 存放于 `.local-data/maps/`。手机每 2.5 秒读取当前实景选择和元数据，图像按内容版本请求；首次初始化后由共用服务持久化，下次打开手机无需加载三维模型。清除服务器数据或浏览器站点数据不等于清除彼此的缓存。

草稿按模型 ID 在当前站点IndexedDB（`village-resident-drafts`）分别保存，称呼和随机本机身份在localStorage（`village-resident`）。不同端口、IP、浏览器是不同本机身份；切换手机/电脑不会自动认领“我的上报”，全村进度仍能查看。清除站点数据会丢失草稿和身份，服务器记录仍保留。

这是本地开发验收服务，没有正式登录、权限、审计、备份、附件对象存储及消息推送。不要直接公开暴露到互联网作为正式治理服务。生产部署需替换业务后台并接入身份认证；手机仅显示当前共享实景的事件，真实村庄切换和投影版本由服务端再次校验。没有真实配准时不能把图像选点当作测绘经纬度。

## 后续 UniApp 迁移

核心契约见 `src/mobile/adapters/contracts.ts`。业务类型和纯函数位于 `domain/`，Web能力放在 `adapters/`，页面不直接调用模型供应商。

| 当前模块 | UniApp替换点 |
| --- | --- |
| React页面、React Router、CSS/native dialog | Vue/UniApp页面、pages.json导航、弹层与安全区组件，需要重写视图层 |
| BrowserRecorder（MediaRecorder/Web Audio） | uni.getRecorderManager，按平台选择服务端支持的录音格式；当前接口只接收规范WAV，其他格式需服务端转码或扩展校验 |
| voiceHttp（Fetch/AbortSignal） | uni.request/uploadFile及任务取消；接口路径和字段保持一致 |
| localResident业务HTTP | 真实后台ResidentGateway与认证token，不能信任客户端residentId作为授权 |
| IndexedDB草稿 | uni.setStorage/getStorage，照片改持久文件路径或对象存储，不能保存临时路径 |
| 相册/拍照与Canvas压缩 | uni.chooseImage/chooseMedia/compressImage，上传后保存附件ID |
| 实景投影地图与共享目录 | 复用 `/api/maps`、PNG、校准元数据及 UV/射线契约；按平台重写图片平移缩放、选点与标记，保留模型与投影版本校验 |

接口与业务可迁移，当前React H5并非开箱即用的UniApp工程。
