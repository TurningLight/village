# 乡居共治｜农村人居环境数字体检与微更新协同平台

一个可操作的乡村治理演示项目，包含独立的桌面管理端和手机村民H5。桌面分为可视化事件处理工作台和智慧治理终端，提供程序化三维村庄、真实模型投影、事件办理、微更新、办结留痕、月度总结及治理分析助手；手机提供实景选点上报、照片、草稿、办理进度与语音填写。程序化村庄布局和预置事件为模拟数据；真实模型投影保留输入模型的纹理与分布。

## 运行

```sh
npm ci
npm run dev
```

`npm run dev` 同时启动三个服务：桌面 http://localhost:5173/，手机 http://localhost:5174/mobile，共用本地API 5190。也可分别运行 `npm run dev:api`、`npm run dev:web`、`npm run dev:mobile`。两端入口、构建与依赖缓存独立，可同时打开。

```sh
npm run build
npm run start
npm test
npm run lint
```

构建产物分别在 `dist/web`、`dist/mobile`。`npm run start` 同时提供桌面5181、手机5184和API5190。语音密钥仅在服务端 `.env.local` 配置，未配置不影响文字上报。手机访问、语音接口、完整验收步骤和UniApp迁移边界见 [手机端开发与测试](docs/手机端开发与测试.md)。

配置百炼Key并准备本机开发证书后，可用 `npm run dev:mobile:https` 在5175单独进行手机录音测试；详见 [语音配置与手机HTTPS测试](docs/语音配置与手机HTTPS测试.md)。用户已确认 vivo 手机通过 HTTPS 测试可用；现有配置继续沿用。

智慧治理终端默认复用服务端已有 `DASHSCOPE_API_KEY`，留痕、月报和助手共用 `qwen-plus`；可用 `GOVERNANCE_API_KEY`、`GOVERNANCE_MODEL`、`GOVERNANCE_BASE_URL` 单独覆盖。配置写在项目根目录 `.env.local`，修改后重启 API 服务即可，不需要重新安装手机证书。操作、统计口径、接口与验收流程见 [智慧治理终端与模型配置](docs/智慧治理终端与模型配置.md)。

使用 React 19、TypeScript、Vite、Fiber 9、Drei、Three.js、MapLibre 与 Zustand。[Fiber 官方兼容说明](https://r3f.docs.pmnd.rs/getting-started/installation)要求 Fiber 9 搭配 React 19；依赖已在 package-lock.json 锁定。没有使用实验版本。

## 使用

- 默认打开青禾村 Demo，无需外部模型、底图或 API 密钥。左键旋转、滚轮缩放、右键平移；点击建筑查看信息，点击事件同步镜头和详情。
- 点击顶部“乡居共治”左侧叶子图标，在「可视化事件处理工作台」(`/`) 与「智慧治理终端」(`/governance`) 之间切换。治理终端沿用工作台当前村庄，不另设一套事件库。
- 桌面默认 3D 主视窗和左下角二维小地图，点击可展开左右对照；工具栏也可切换 3D、2D 或分屏。地图事件与3D共用选中状态。
- 在「治理事件」按类别或状态筛选，统计、三维标记、地图和列表同步变化。「新增事件」后点击三维地面或建筑，填写标题、区域和说明。
- 在事件详情中受理、记录处理说明、确认办结，或重新受理。完整历史保留，已办结事件可筛选查看。默认全量视图保留绿色办结标记。
- 办结并同步到 API 后自动进入治理终端，模型按已记录的流程与结果生成一段工作留痕，按有效办结月份归档。该批留痕处理完成后自动生成月度总结：服务端提供统计段，模型只复盘有效已办结留痕中的措施与结果；可查看原事件、重试失败任务、更新月报、复制或下载文本。重新受理会撤回原留痕并使旧月报待更新，保留历史，不把旧结论继续当作有效成效。月报更新成功前保留上一版及其原来源，避免正文和来源混配。
- 在治理终端点击机器人图标使用「村庄治理分析助手」。助手引用当前村庄与所选月份的事件依据，分析记录集中地点与办理情况，并提出建议。关闭后恢复终端视图；切村或换月会开始新的对话。当前助手只读，不自动修改事件。
- 在「微更新」选择路灯、广场或垃圾点方案，切换改造前后。路灯修复请切到夜间查看。方案切换会真实改变灯光、铺装、长椅、树木、垃圾和分类设施；仅预览，不自动修改事件状态。
- 「图层」支持建筑、事件、道路、农田、水域、公共设施、微更新和小地图的显示控制。
- 切到「实景模型」，通过「地图设置」继续使用 Sketchfab 或上传本地 GLB/glTF。模型与事件按模型 ID 隔离，原有数据保留。上传详见 [本地实景模型上传与测试](docs/本地实景模型上传与测试.md)。
- 手机自动跟随电脑最后选择的真实村庄，每 2.5 秒检查村庄与投影更新，不提供 Demo 或手动选村。首页可进入实景地图，「随手报」直接在同一二维影像上选点；切村时事件和草稿隔离。电脑切回 Demo 时，手机继续显示最后的真实村庄。首次没有共享实景时显示等待；换村后新底图未就绪时不沿用旧村图。详见 [手机实景底图与录入](docs/手机实景底图与录入.md)。

## 数据与边界

`src/data/villageLayout.ts` 是共享几何来源。`src/lib/spatial.ts` 生成带相同对象 ID 的 GeoJSON；`src/lib/coordinate.ts` 定义虚构锚点与米制坐标转换，按演示纬度修正经度距离。

实景二维视图会从当前模型生成带纹理的投影底图：本地 GLB/glTF 使用严格正交投影，Sketchfab 使用经相机校准的小视角俯视影像。底图与事件共用投影参数，新村庄首次生成后按模型长期保存本地，刷新直接恢复；记住二维视图且有缓存时无需加载三维模型。支持缩放和平移。详见 [通用实景投影](docs/通用实景投影.md)。上传模型没有自动建筑分割或测绘配准，建筑数量不会用演示数据冒充；影像保留模型中的建筑和分布，不表示真实经纬度。三种预设改造仅在程序化村庄生效。Sketchfab 需要联网，已有实景夜间模式是视觉模拟。青禾村场景与本地模型由本地 Web 服务提供时不需要外网，但没有添加离线应用缓存。

桌面把当前实景村庄、校准元数据和 PNG 自动共享到本地API；目录与图像持久化在 `.local-data/maps/`，图像按内容版本缓存。手机访问同一API即可恢复已共享底图，无需加载或重新渲染3D。二维选点保存模型标识、原图 UV、投影版本和射线，三维定位只在真实网格命中时显示；不生成虚构 GPS 或建筑高度。底图更新后未获得可靠三维锚点的旧版位置不在新图上猜测显示，记录仍可从列表查看。提交时服务端校验当前实景和投影版本，过时请求返回409。

事件与照片共用本地API并持久化到 `.local-data/issues.json`，两端通过轮询同步；浏览器继续保留 `village-issues` 副本和同源storage通知。模型及来源继续使用原IndexedDB；场景选择另存 `village-scene-mode`。手机草稿按模型 ID 分别保存在当前站点浏览器，身份也仅在当前站点保存，换设备不会自动认领“我的上报”。当前API没有正式认证，适用于本地演示验收。

治理档案与月报保存在 `.local-data/governance.json`，以事件源版本检测变更，生成期间资料变化时丢弃过时结果。按 Asia/Shanghai 计算所选月上报量、当前仍有效的办结量和办结耗时；当前待处理数包含往月事项，不直接计算为“本月办结率”。地点按录入名称聚合，不做 GPS 聚类，也不能推断真实事故率或因果；“村内选点”等泛称应先核实具体位置，不能并作同一事故集中地点。模型只接收脱敏后的有限文字上下文，不包含照片、身份字段或原始坐标；自由文本脱敏并不保证绝对匿名。历史无模型锚点资料沿用工作台兼容归属，并明确提示来源需核实。完整的字段、截断及模型判断边界见治理终端文档；实现借鉴见 [治理助手实现参考](docs/治理助手实现参考.md)。

`src/services/issueService.ts` 定义浏览器仓储边界，`src/services/sharedIssueSync.ts` 同步本地API，`src/store/useAppStore.ts` 执行管理端新增与状态命令。手机 `src/mobile/adapters/contracts.ts` 抽象业务、草稿、录音与语音服务；服务端语音代理在 `server/voice.mjs`。接入正式后台时应增加认证、事务与服务端状态命令；PostGIS需保存模型标识、投影版本及图像 UV/射线、实际网格命中坐标，以及经核实后才可使用的地理配准关系，不应把当前演示锚点当作实测值。

## 目录

```text
src/
  App.tsx                       工作区、场景来源与视图编排
  components/
    scene3d/                    程序化村庄、实景模型、相机、设施改造
    map/                        MapLibre 与 WebGL 失败回退
    governance/                 事件、建筑详情、办理时间线、微更新面板
    governance-terminal/        办结档案、月度汇报、只读治理分析助手
    issues/                     共用事件录入表单
    layout/                     品牌、统计
  data/                         村庄几何、事件、方案
  lib/                          坐标、GeoJSON、模型读取与保存
  services/                     本地事件仓储和同源通知
  store/                        Zustand 共享状态
  types/                        统一业务与空间类型
  mobile/                       独立村民H5、领域函数与平台适配
server/                         共用本地事件/实景底图API、语音与治理模型代理、静态服务
shared/governanceFacts.mjs      服务端与前端共用的治理事实与证据边界
scripts/                        双端并行开发/运行编排
tests/                          事件、模型、在线校验、空间与治理回归
docs/                           使用说明与阶段验收记录
```
